# Template AI Interaction Log, PPB Remidi 7 Pertemuan

> **Status:** v1.0, 2026-08-08
> **Aplikasi jangkar:Remedial Task Tracker** (7 sesi, 2 assignment + 1 proyek akhir)
> **Tujuan:** template wajib untuk mendokumentasikan setiap pemakaian AI pada tugas remidi.
> **Aturan:** AI Interaction Log wajib dilampirkan pada setiap tugas **bila kamu memakai AI**. Tidak melampirkan padahal memakai AI = pelanggaran kebijakan (lihat `Panduan-Mahasiswa.md` bagian 5).

> **Log ini bukan pengganti narasi.** Setiap tugas juga mewajibkan **Narasi Pemanfaatan AI** (karangan 800-1500 kata di README §7). Hubungan keduanya: **log ini adalah bahan mentah, narasi adalah hasil olahannya.** Isi log sambil bekerja, terutama kolom "perubahan yang ditolak", lalu rangkai jadi narasi saat menyusun submission. Mengisi log dengan rajin membuat narasi jauh lebih mudah dan jauh lebih spesifik.

## Cara pakai

1. Salin template di bagian "Interaksi" untuk **setiap** sesi pemakaian AI (boleh beberapa kali per tugas).
2. Isi semua field. Field kosong = log tidak lengkap.
3. Bagian "Verifikasi pemahaman" wajib diisi, inilah bukti bahwa kamu menguasai, bukan sekadar menempel.
4. Sertakan **screenshot** tiap interaksi (layar AI + hasil di kodemu) bila diminta dosen.
5. Kumpulkan sebagai bagian README tugas atau file `ai_interactions.pdf`/`AI-LOG.md` terpisah.

## Kebijakan AI singkat

| Sesi | Boleh | Tidak boleh |
|---|---|---|
| P1-P3 | penjelasan syntax, diagnosis error | menulis core logic tanpa analisis sendiri |
| P4-P5 | debugging, review error | tidak memahami perubahan data layer sendiri |
| P6-P7 | ide test/optimasi | tidak mencatat interaksi AI |

Saat demo kamu harus bisa menjelaskan kode yang dibantu AI. Log yang rapi mempermudah kamu mengingat dan membuktikan penguasaan.
